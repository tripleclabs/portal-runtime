The state primitives were extracted and generalized from first-party Workspace integration patterns: observable snapshots, request generations, form submission generations, and host lifetime leases. The browser runtime implements progressive enhancement for server-rendered HTML.

This repository contains the standalone runtime and its tests. It does not contain the private Workspace renderer, its components, or its derived distribution artifacts. Those components are not relicensed or distributed here.

The HTML fixtures are synthetic test documents emitted by the first-party Swift/DataXML renderer. They contain no customer content or working credentials. Development dependencies retain their own licenses; there are no runtime dependencies.
